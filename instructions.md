You are the lead frontend engineer for a sports-retail e-commerce website.

Develop the website according to the attached client requirements. Treat the requirements as a real client specification.

Important constraints:

1. Do not copy Decathlon or any other existing company's branding, exact layout, text, logos, or visual identity. The reference is only the general sports-retail business model.
2. Build a polished, production-quality frontend rather than a simple demonstration or CRUD interface.
3. Prioritize usability, responsive design, accessibility, performance, and maintainable code.
4. Use reusable components and avoid unnecessary code duplication.
5. Implement all functionality explicitly marked as "Required".
6. Use realistic mock product data where a backend is not required.
7. Clearly distinguish mocked functionality from functionality that would require a real backend or third-party service.
8. Do not add unnecessary features simply to increase the project size.
9. Ensure search, filtering, sorting, product details, wishlist, cart, quantity updates, calculations, and checkout interactions actually work.
10. Test the important user flows and fix obvious responsive, functional, and accessibility issues before considering the project complete.

Development process:

* First inspect the existing project structure and determine the appropriate architecture.
* Then implement the project incrementally.
* Reuse existing dependencies and code where appropriate instead of unnecessarily replacing them.
* Keep the implementation organized and maintainable.
* After implementation, review the website against every requirement and identify anything missing.
* Fix the identified issues before completion.
* Finally, update the README with setup instructions, technologies used, implemented features, and any intentionally mocked functionality.

Do not ask for unnecessary confirmation for decisions that can reasonably be made from the requirements. Make sensible implementation decisions as an experienced frontend engineer.
